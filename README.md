# Aiden Zhang

Hey, my name is Aiden. I'm a first-year student at the University of Waterloo studying Computer Engineering. This is my portfolio website, where I share my experiences and some of the things I have built or am building. Feel free to contact me at [a522zhan@uwaterloo.ca](mailto:a522zhan@uwaterloo.ca) or [aidenzhangg.0@gmail.com](mailto:aidenzhangg.0@gmail.com).

The website is built with React, TypeScript, and Vite. It opens with a Windows-inspired lock screen before showing a desktop-style portfolio with a taskbar and a movable window. `src/App.tsx` handles the main layout, navigation, and individual project pages. `src/profile.json` stores the projects, technical skills, experience, extracurriculars, and certifications. `src/useWindowControls.ts` manages dragging, minimizing, maximizing, and restoring the window. `src/ProjectPhotos.tsx` displays project photos and website screenshots, while `src/ContactForm.tsx` sends contact messages through FormSubmit. The styles live in `src/App.css` and `src/index.css`, and images, icons, and PDFs are stored in `public/`. Run `npm install` followed by `npm run dev` to work on the site locally, or `npm run build` to create the production files in `dist/`.
